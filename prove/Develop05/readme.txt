
# Eternal Quest (C# Console)

A gamified goal tracker with Simple, Eternal, and Checklist goals. Earn points, track progress, and get creativity bonuses. Built with OOP design: inheritance, polymorphism, encapsulation.

## Features
- Simple goals: one-time completion, award points.
- Eternal goals: never complete; award points every record.
- Checklist goals: complete N times; per-event points + final bonus.
- Create goals, record events, list status ([ ] / [X], progress).
- Live scoreboard in the menu.
- Save & load text file.
- Creativity points (streak/combos).
